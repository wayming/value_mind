### 股权成本

高增长期：COE = Rf + (β + beta_risk_adjustment) × ERP = 2.0% + (1.05 + 0.05) × 6.0% = 2.0% + 1.10 × 6.0% = 8.6%。稳定期：COE_terminal = Rf + terminal_beta × ERP = 2.0% + 1.0 × 6.0% = 8.0%。

β 判断依据：(1) 行业起点——中国大型国有/股份制银行 β 通常 0.6–1.0，低于美国货币中心银行 1.2 的量级（经营更稳健、A 股市场 β 特性不同）；(2) 业务风险调整 +0.05——招行交易/证券化/投行业务占比低（交易性金融资产约 3.66 万亿元，占总资产 13.5 万亿元约 27%，且无主导投行牌照），不构成高风险业务上调理由；但零售信贷（信用卡、消费贷）在经济下行期资产质量承压、财富管理手续费收入与资本市场景气度高度相关（2025 年非利息收入同比 -10.6%），叠加高杠杆（权益/资产 ≈ 9.6%，权益乘数约 10.4x）放大股权风险，故给予小幅上调而非下调；(3) 增长联动——招行 ROE 约 12%、派息率约 33–35%，隐含高增长期 g = ROE × (1−派息率) ≈ 7.9%，按第九章硬约束 COE 必须大于 g，故 β 取高值使 COE = 8.6% > 7.9%，避免"低 β + 高增长"的自相矛盾组合。

稳定期 β 取 1.0（第九章明确：稳定期 β 趋 1，富国银行例 3.6% + 1×5% = 8.6%），对应 COE 8.0%，高于稳定期 g（约 4–5%），模型可解。

监管提示：中国银行业面临资本要求趋严、净息差收窄（LPR 下行）与零售资产质量压力，未来监管与宏观变化可能改变银行风险程度与 β；若监管进一步趋严或增长显著放缓，应相应下调 β 与 COE。

自检：高增长期 COE 8.6% > g 7.9% ✓；稳定期 COE 8.0% > 稳定期 g 4–5% ✓。参数内部自洽。

### 股息贴现模型(DDM)

【适用性】skill 03 已确认 dividends_reliable = true：DPS 自 2016 年 0.74 元持续增至 2024 年 2.00 元，派息率多年稳定在 33–35%，股息率约 5%，分红可持续性强，满足 DDM 使用前提，故 ddm_applicable = true。

【输入自洽性】g_high = ROE × (1 − payout) = 12.5% × (1 − 0.34) = 8.25%，与 skill 03 的 growth 完全一致，偏差 0%，无警告。COE_high = 8.6% > g_high = 8.25%，模型不发散，但利差仅 0.35%，极为紧张，是本模型最脆弱之处。

【高增长期假设】eps0 = 5.70，为 2025 全年 EPS（Q1 1.48 + Q2 1.41 + Q3 1.54 + Q4 1.26 ≈ 5.70），最近完整年度口径。payout_high = 0.34，沿用 skill 03 的年度 DPS/EPS 自算口径（2024 = 2.00/5.66 ≈ 0.353，多年均值 0.34），不含回购（2025 年 500 亿回购为单笔非惯例，不纳入复合派息率）。g_high = 8.25% 由 ROE×(1−派息率) 机械决定，未凭空拍高。stage_years = 5，沿用第九章富国银行例的典型高增长期；招行受监管资本约束，增长期不宜过长。

【稳定期（终值）假设】g_terminal = 3.0%，与书例一致，量级接近无风险利率（2%）与长期名义 GDP 增速上限，略高于 Rf 属偏乐观但符合成熟优质银行惯例。roe_terminal = 8.6%，稳定期 ROE 趋近稳定期 COE——高回报终被竞争与监管磨平（招行当前 ROE 12.5% 将向 8.6% 收敛）。coe_terminal = 8.0%，稳定期 β→1，Rf 2% + 1×ERP 6% = 8.0%，与全局参数一致。稳定期派息率 = 1 − g/ROE = 1 − 3.0/8.6 = 65.1%，由公式决定，非自由参数。

【关键风险与取舍】1) COE_high 与 g_high 利差过窄（0.35%）——最高频失败点。8.25% 的机械 g 对一家受监管资本约束、NIM 结构性压缩的成熟银行偏高；skill 02 给的 β_effective = 1.1 → COE 8.6%，与 skill 03 的 g = 8.25% 几乎相撞。若 Python 报错或结果异常，应优先上调 β（第九章原则：期望高增长的银行应有较高 β，8% 增长不该配 1.1 的低 β），或下调高增长期 g 至更贴近名义 GDP 的水平（如 5–6%）并说明理由；此时 g 与 ROE×(1−派息率) 的偏差会触发自洽性警告，属正常，忠实反映“假设增长与当前 ROE/派息率不相容”。2) 机械 g 的陷阱：ROE 12.5% + 派息 34% → 留存 66% → g 8.25%，但银行资产扩张受资本与市场容量约束，长期 g 不可能持续高于名义 GDP；本模型高增长期仅 5 年尚可接受，延长 stage_years 会显著高估。3) 终值占比过大：高增长期股息现值占比很小（利差仅 0.35%，几乎可忽略），估值几乎全部来自终值，因此 g_terminal、roe_terminal、coe_terminal 比高增长期参数重要得多，终值假设的微小变动会主导每股价值，分析中须明确终值占比。4) 监管风险在 β 里：未来监管趋严 → β 上调 → COE 上升 → 价值下降；招行核心一级资本充足率约 14%，缓冲充足，短期摊薄风险低，但低利率环境下 ROE 难回 16%+ 周期高点，已通过 roe_normalized = 12.5% 反映。

【结论】参数组自洽（偏差 0%），可直接供 Python 计算。但需警惕 COE_high 与 g_high 利差过窄——若计算报错或结果对参数极度敏感，应回到 β 与 g_high 重新自洽化，而非放弃 DDM。
