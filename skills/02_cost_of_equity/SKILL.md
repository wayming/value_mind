# 股权成本估算(COE = Rf + β × ERP)

## 目标

产出高增长期与稳定期两个股权成本,供 DDM、监管资本 FCFE、超额回报模型共同使用。
你只负责**判断参数**(β、Rf、ERP 及调整理由),计算由 Python 完成。

## 数据获取(MCP 工具)

- `list_metrics` 确认可用的比率指标(ratios 组,如 roe、pb、pe);同一节点内不必重复调。
- **MCP 没有 beta 指标,也没有价格历史序列**——β 无法从数据计算,必须基于行业知识假设,
  并在 beta_source 中写明依据。不得声称"由数据计算得出"。
- 如需公司体量/结构信息辅助判断 β,可调 `get_financials` 取 marketcap、assets 等少量指标;
  **一次调用就把本节点要用到的全部指标带上**(体量/结构 + 参照指标),不要为了一两个辅助指标
  再抓一次 —— 本节点最多 2 次 `get_financials`(代码强制),零散调用会把额度耗在补漏上。

## 分析步骤

1. **行业 β 起点**:金融服务领域上市公司众多,估算行业 β 相对容易。对商业模式类似的银行,
   采用同类银行的平均 β。参考量级:美国大型货币中心商业银行 β ≈ 1.2(第九章富国银行例,2008 年)。
   中国大型国有/股份制银行通常更低(约 0.6–1.0,经营更稳健、市场 β 特性不同),自行判断并写明理由。
2. **业务风险调整**(beta_risk_adjustment):开展高风险业务的金融服务公司——证券化、交易、投资银行
   业务——应该有更高的 β。对照你的公司:高风险业务占比高 → 上调(如 +0.1~+0.3);纯传统存贷 → 0 或小幅下调。
3. **考虑风险与增长的关系**:期望获得高增长的银行应配较高的 β。若公司处于高增长阶段,
   β 取高值;同时记住:当增长率降下来时,β 也要随之减小。
4. **Rf**:取与公司现金流同币种、同期限的政府债券收益率(如美国/中国 10 年期国债),标注期限与来源。
5. **ERP**:成熟市场约 5% 量级(第九章用 5%);新兴市场(如中国 A 股)通常上调至 6–8%,写明理由。
6. **稳定期**:第九章明确——稳定期中 β 趋 1(富国银行例:稳定期 COE = 3.6% + 1×5% = 8.6%)。
   除非有强理由,terminal_beta 取 1.0。

## 坑与注意点

- **β 和增长率必须联动(双向)**:第九章明确"期望获得高增长的银行有较高的 β(以及股权成本)",
  并且"从较高的股权成本率开始,当你减小增长率时,也要减小 β 系数和股权成本率"。
  这条规则是硬约束:**COE 必须大于你假设的增长率 g**,否则 DDM 等模型无解。
  自检方法:算出你的 β 后心算 COE = Rf + β×ERP,再对比 skill 03 的 g = ROE×(1−派息率):
  - 若 g ≥ COE(常见于"低 β + 高 ROE + 低派息率"的组合)→ 假设不自洽。合理反应是**提高 β**
    (承认高增长伴随高波动,书中原则),或调低增长假设并相应说明。
  - 不要一边假设 8% 的高增长、一边用 0.85 的低 β —— 这是自相矛盾的组合。
- **监管变化会改变风险**:第九章富国银行例的估值发生在金融危机爆发 4 周后,未来监管变化
  (资本要求提高)会改变银行的风险程度与 β。若公司面临监管趋严,应在理由中提及。
- **不要用公司自己报告的 β**(若有的话):估值应基于同类公司平均与业务判断。
- Rf 与 ERP 的币种、期限必须与估值对象一致;不要混用中美利率。
- 注意 β 与资本结构:高杠杆银行(权益/资产比率低)股权风险更大,β 应更高。

## 何时不适用

- 公司数据完全缺失且无法判断业务性质时,仍可基于行业常识给出参数,但必须在理由中明确标注
  "纯假设"。

## 输出参数

按 schema(CostOfEquityParams)输出:beta、beta_source(依据!)、beta_risk_adjustment、
terminal_beta(默认 1.0)、rf、rf_tenor、erp、erp_rationale、analysis。

## 公式(Python 计算,你不需要算)

- 高增长期:COE = Rf + (β + beta_risk_adjustment) × ERP
- 稳定期:COE_terminal = Rf + terminal_beta × ERP
- 书例:3.6% + 1.2×5% = 9.6%
