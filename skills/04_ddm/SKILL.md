# 多阶段股息贴现模型(DDM)

## 目标

股票价值 = 高增长期股息的现值 + 期末价格(永续增长)的现值。
本 skill 负责**阶段假设的判断**;贴现计算由 Python 完成。

## 何时使用 / 不适用

- **使用前提**:skill 03 判定 dividends_reliable=true(持续、可预测派息)。
- **不适用**:投行/投资公司等股息不稳定者,或不派息公司 → 输出 ddm_applicable=false 并写 skip_reason,
  由监管资本 FCFE 与超额回报模型替代。

## 数据获取(MCP 工具)

- 需要 EPS 起点与每股股息:调 `get_financials` 取 epsBasic、dps、bvps(用于交叉校验)。
- **口径不用你判断**:上下文里的「Python 判定口径后的年度数据」已经把这些指标换算到
  12 个月(年度)口径并给了判定依据。MCP 返回的原始序列口径混杂(同一条序列里可能前几年
  是年报值 ÷4、之后是 12 个月 TTM),**直接采用上下文里的值,不要自己换算、也不要靠
  数值量级猜口径**——这条错了,整条预测股息序列会缩水到 1/4。
- 若 skill 03 已提供 dps_by_year,不必重复抓取。

## 分析步骤

1. **确认输入自洽性**:DDM 有三组输入——股权成本(COE)、派息率、股息增长率——三者必须互相不冲突。
   g_high 必须 ≈ ROE × (1 − 派息率)(Python 会校验并警告,偏差超过 0.5% 说明参数有问题)。
2. **高增长期假设**:
   - eps0:最近 12 个月(TTM)的每股收益,取上下文「Python 判定口径后的年度数据」里的
     `epsBasic`(已年化;若尾部那点被改成过坏点,依据里会写明)。
   - payout_high:沿用 skill 03 的派息率结论(含回购调整的口径要保持一致)。
   - g_high:由 ROE×(1−派息率) 决定,通常 4–8% 量级;不要凭空拍高增长。
   - stage_years:高增长能持续多久?典型 5 年(第九章富国银行例),受监管约束的行业增长期不宜过长。
3. **稳定期(终值)假设**:
   - g_terminal:永续增长率,不超过无风险利率量级(富国银行例 3%)。
   - 稳定期 β 趋 1(COE_terminal = Rf + 1×ERP,富国银行例 8.6%)。
   - roe_terminal:稳定期 ROE 趋近稳定期 COE(富国银行例 8.6%)——高回报终会被竞争与监管磨平。
   - 稳定期派息率由公式 1 − g/ROE 决定(约 65%),不是自由参数。
4. **一致性检查**:g_high 与 ROE×(1−派息率) 是否自洽;COE 必须大于 g(否则模型发散,Python 会报错,
   报错后应调低 g 或调高 COE,而不是放弃)。

## 坑与注意点

- **COE ≤ g 模型崩溃(最高频的失败原因)**:`COE_high` 必须大于 `g_high`,否则 Python 会报错。
  发生时报错信息会给出补救方向,不要因此放弃 DDM,而是回到参数重新自洽化:
  - 常见成因:skill 02 给的 β 偏低,而 skill 03 的 g = ROE×(1−派息率) 偏高。
  - 补救一(推荐):提高 β —— 第九章原则是"期望高增长的银行有较高的 β",8% 的增长本就不该
    配 0.85 的低 β。
  - 补救二:承认机械算出的 g 对成熟银行不可持续,**下调高增长期 g** 至 COE 以下并说明理由
    (例如长期增长受名义 GDP 约束);但此时须注意:g 与 ROE×(1−派息率) 的偏差会触发自洽性
    警告,这是**正常的**——它忠实反映了"你假设的增长与当前 ROE/派息率不相容",在 analysis
    中写清取舍即可,不必强行消除警告。
- **机械 g 的陷阱**:对于 ROE 高、派息率低(留存多)的银行,ROE×(1−派息率) 会算出偏高的 g
  (如 ROE 12%、派息 34% → g 8%)。但银行受监管资本约束,资产扩张受资本与市场容量限制,
  长期 g 不可能长期高于名义 GDP 增速。遇到这种矛盾,应在 analysis 中明确指出并作出选择。
- **回购口径**:若 skill 03 用了复合派息率(含回购),DDM 的股息序列也应按该口径(股息+回购),
  否则低估价值。payout_high 的含义必须与 skill 03 保持一致。
- **终值占比过大**:高增长期股息现值占比通常很小,估值几乎全部来自终值——所以终值假设
  (g_terminal、roe_terminal、COE_terminal)比高增长期参数重要得多,要格外慎重。
  在 analysis 中说明终值占估值的比例是否过高。
- **监管风险在 β 里**:未来监管趋严 → β 上调 → COE 上升 → 价值下降,阶段假设要考虑监管环境。

## 输出参数

按 schema(DdmParams)输出:ddm_applicable、skip_reason、eps0、payout_high、g_high、stage_years、
g_terminal、roe_terminal、coe_terminal(可为 None,缺省用高增长期 COE)、analysis。

## 公式(Python 计算,你不需要算)

- 高增长期:EPS_t = EPS0 × (1+g)^t,D_t = EPS_t × 派息率,t = 1..stage_years
- 稳定期派息率 = 1 − g_terminal / roe_terminal
- 终值 P_T = D_{T+1} / (COE_terminal − g_terminal)
- 每股价值 = Σ D_t/(1+COE)^t + P_T/(1+COE)^T
- 书例(富国银行,2008-10):EPS0≈2.18、派息 54.63%、g 6.13%、5 年、终值 g 3%、
  COE 9.6%→8.6% → 每股约 27.74 美元
