# 超额回报模型

## 目标

股权价值 = 目前投入的股权资本 + 股权投资者预期超额回报的现值。
最有趣之处在于**侧重超额回报**:赚市场平均回报 → 市值趋近账面;赚不到 → 市值低于账面。
核心判断:**超额回报(ROE − COE)能维持多久**。

## 何时使用 / 不适用

- 几乎总是适用:只要股权账面价值可观察(equity 指标存在)。
- 不派息公司也能用(不同于 DDM)。

## 数据获取(MCP 工具)

- `get_financials` 取 equity、bvps(每股账面价值)、roe(与 skill 03 的归一化 ROE 对口径)。
- 不需要价格数据。

## 分析步骤

1. **基数**:bv_equity(当前股权账面价值)、bvps(用于换算每股)。
2. **ROE**:roe_current 与 skill 03 的 roe_normalized 保持一致——超额的 ROE 才有意义,
   被危机/监管压低的 ROE 会低估超额回报。
3. **核心判断——超额回报的期限与回归**:
   - years_high:高 ROE 能维持几年?竞争优势(牌照、客户粘性、进入壁垒)越强越久。
   - years_fade:随后几年线性衰减到 roe_terminal(均值回归路径)。
   - roe_terminal:理论上回归到股权成本(超额回报终会消失);如认为永久不回归,
     使用永续模型(见下,它给出的是乐观上界)。
   - mean_reversion_rationale:回归依据——竞争、监管趋严、高 ROE 业务(交易/投行/地产/PE)
     伴随高风险,第九章强调要**同时看账目两边:业务活动产生的 ROE,以及带来的风险**;
     新业务高回报的好处可能部分或完全被高风险抵消。
4. **派息率(payout)**:用于逐年增厚股权账面价值(留存收益),沿用 skill 03 结论。
5. **两种口径都会由 Python 计算**:
   - 永续模型(ROE 永不回归)= 乐观上界
   - 衰减模型(均值回归)= 中央值
   估值区间参考两者。

## 坑与注意点

- **书中数字勘误**:第九章富国银行例,超额回报现值印的是"约 582.2 亿美元、股权价值 1058.5 亿
  美元",这是翻译/印刷错误。按公式实算:超额回报 PV = 476.3亿×(13.51%−9.6%)/9.6% ≈ **194 亿
  美元**,股权价值 ≈ **670 亿美元**,每股 28.38 美元(与书中每股 28.38 一致)。以公式为准。
- **ROE < COE 是合法结果**:价值低于账面,说明市场认为公司正在毁灭价值——不要"修正"它。
- **高 ROE 高风险的权衡**:只提高 ROE 的假设而不提高 COE(β)会高估;两者要联动。
- **监管变化框架**:资本要求提高 → ROE 下降 → 超额回报下降 → 价值下降,判断时要纳入监管预期。
- 账面股权可能包含无形资产(品牌、人力资本),金融服务公司资产按市价计量使账面价值
  更接近市场价值,这也是超额回报模型在金融行业尤其适用的原因。

## 输出参数

按 schema(ExcessParams)输出:applicable、bv_equity、bvps、roe_current、roe_terminal、
years_high、years_fade、payout、mean_reversion_rationale、analysis。

## 公式(Python 计算,你不需要算)

- 超额股权回报_t = (ROE_t − COE) × 股权_{t-1}
- 永续:超额回报 PV = BV × (ROE − COE) / COE;股权价值 = BV + 超额回报 PV
- 衰减:ROE 线性衰减,bv_t = bv_{t-1}×(1+ROE_t×(1−派息率)),逐年贴现 + 终期收尾
- 书例(富国银行):BV 476.3 亿、ROE 13.51%、COE 9.6% → 每股 28.38 美元
